# S3 — `tapnshow.vercel.app` as a verified, authorized OAuth domain

- **Date:** 2026-10-05
- **Question:** Can `tapnshow.vercel.app` be verified in Google Search Console and accepted as an OAuth authorized domain? (spec §9, §13)
- **Result:** **PASS** — Google OAuth app verification can proceed on the free `vercel.app` subdomain; no domain purchase is needed for verification.

## Steps and evidence

1. `vercel.app` is on the Public Suffix List (checked 2026-10-04), so `tapnshow.vercel.app` is its own "top private domain".
2. Search Console → URL-prefix property `https://tapnshow.vercel.app/` → HTML tag method.
3. The tag is rendered by Next.js metadata from `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` (set in Vercel Production, redeployed). Confirmed live:
   `<meta name="google-site-verification" content="Kiv0gJjj2_cUvJjRJ2-agHxruIadWwf8rysfKcOI3zQ"/>`
4. Search Console: **Verified** (owner report).
5. Google Cloud project `tapnshow` → Google Auth Platform → Branding → Authorized domains → `tapnshow.vercel.app`: **Accepted** (owner report).

## Consequences

- M9 verification submission can use `https://tapnshow.vercel.app` for the home page, privacy policy and terms.
- Keep `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` set in Production; removing it can revoke the Search Console ownership.
